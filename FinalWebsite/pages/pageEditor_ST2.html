Header and Footer

This page establishes the main structure of the website, ensuring a consistent layout and seamless navigation. It includes a header with a logo, a navigation bar, a wrapper for content, and a footer. The navigation bar provides links to essential pages such as the home page, volunteer page, table page, profile page, feedback page, sitemap, and team page, allowing users to move effortlessly throughout the site. A profile icon is also incorporated into the navigation bar for easy access to user-related features.

The HTML structure follows semantic best practices, using a "nav"element for the navigation bar, a "header" for branding, and a "footer" for relevant links. An external CSS file ensures global styling consistency across all pages. The logo and profile images are included using "img" tags with alt attributes, making the website accessible for screen readers. The navigation menu is structured with an unordered list "ul>", ensuring clarity and ease of use.

CSS Flexbox (display: flex;) is used to structure the navigation bar, ensuring responsiveness across different screen sizes. Padding and margin adjustments create spacing between elements, and hover effects (:hover) enhance user interaction. The profile icon is styled with border-radius: 50%, creating a modern circular look. The wrapper section is designed to hold the main content, ensuring flexibility for future content additions.

The footer maintains a fixed position, ensuring it remains visible at the bottom of the page. It includes links to the Editor’s Pages of all students, providing access to individual contributions. The page follows accessibility best practices, ensuring proper color contrast and responsive design. By using modern HTML and CSS techniques, this page ensures a structured, user-friendly, and visually appealing website experience.

Home page

It highlights the website's goal of providing easily accessible and patient-centered healthcare information with a hero section that includes a background image, headline, and description. Overall, this home page combines semantic HTML, CSS interactivity, and responsive design principles to create a visually appealing and user-friendly interface that aligns with the Sustainable Development Goals (SDG) theme.

4. Challenges & Lessons Learned

One of the major challenges was ensuring consistency in design across all pages while collaborating with team members. To overcome this, a global CSS file was implemented, ensuring uniformity in fonts, colors, and layouts.

Another challenge was ensuring responsiveness across different devices. By using CSS Flexbox and media queries, the website was made fully adaptive.

Debugging navigation links and maintaining accessibility compliance were also key learning areas. Ensuring alt text for images and proper color contrasts improved usability and accessibility.

5. Accessibility

The website adheres to accessibility principles by:

  • Using semantic HTML elements such as <nav>, <header>, and <footer> for structure.
  • Providing alt text for images to assist screen readers.
  • Ensuring sufficient color contrast for readability.
  • Using keyboard-friendly navigation.
