Splash Page

Technical Description

I created splash screen using HTML and JavaScript.JavaScript help me to add countdown to the home page.

<h1><u>HEALTH IS THE GREATEST WEALTH</u></h1>

<h3>We promise to bring your health into next level</h3>

<div class="loader"></div>

<script>

let count = 4; // Set initial countdown value

let countdownInterval = setInterval(() => {

count--;

if (count === 0) {

clearInterval(countdownInterval);

window.location.href = '';

}

}, 1000);

</script>

Accessibility

I used <h1> and <h3> tags for headings, which helps screen readers understand the structure. The <html lang="en"> tag tells screen readers the content is in Englis and making it easier for them to read it correctly and get understand perfectly.

JavaScript implements a 4-second countdown that may immediately redirect users, which may be too quick for some people, those using screen readers for example. Solve this by adding a Pause button. For example, <button id="pause"> Pause <button> could be added to the HTML, while in the script, the countdown is paused on click. This will then give users control over the timing.

The <div class="backgroundImage"> and <div class="loader"> are visual elements that do not give any information to screen readers. But if they just serve aesthetic purposes—so be it, leave them like that.

Technical Description

<html lang="en">: Specifies the document's language (English), important for accessibility and search engines.

<meta charset="UTF-8">: Ensures proper encoding for special characters.

<meta name="viewport" content="width=device-width, initial-scale=1.0">: Makes the page responsive by adjusting it for different screen sizes.

<header> & <nav>: Contains the logo and navigation, essential for page structure and user navigation.

<section>: Organizes content into distinct sections for better readability and accessibility.

<a href="#top">: Provides anchor link functionality, allowing users to return to the top of the page.

CSS:

.firstimage:

background-image: Sets a background image for the section.

width: 100% and height: 500px: Ensures the image covers the section and maintains a consistent height.

border-radius: 30px: Rounds corners for a visually appealing look.

.mainHeading:

text-align: center: Centers the main heading for balance.

background-color: Adds a branded color background to the heading.

.go-top:

position: fixed: Keeps the "Go to top" button visible while scrolling.

background-color and color: white: Ensures the button stands out and is easily readable.

Hover Effects:

.go-top:hover changes text color when hovering to provide user feedback.

Accessibility

The HTML structure of the page prioritizes accessibility to ensure an inclusive user experience. The html lang="en" tag specifies the document's language, helping screen readers pronounce content correctly. The <img> tags include <alt> attributes, providing descriptions for images to assist visually impaired users. Semantic tags like <header>, <navr>, <section>, and <footerr> enhance the organization of content, making it easier for assistive technologies to interpret the page layout. Interactive elements, such as the a href="#top" link, allow users to navigate back to the top of the page, offering greater convenience. Additionally, large, bold text and hover effects on buttons improve readability and user interaction, particularly for those with visual or motor impairments. These techniques collectively create a more accessible and user-friendly website.

Challenges and Lessons Learned

One challenge I face when putting a countdown timer on the splash page was to make sure it was working for all users especially those using screen readers; having an auto-redirection after 4 seconds seemed a little rushed for some. Therefore, I provided a pause button for the user to control the countdown. In addition, I had to ensure that the pause button would be clear and easy for everyone to use. This experience taught me how important it is to give control over time-sensitive features to users, especially in light of accessibility. I made sure that buttons and text were easy to see and use when styling the page. For instance, I made the "Go to top" button stand out more with a hover effect, but I also had to think about color choices to make sure they were clear for colorblind users. Testing color contrast was a lesson I learned. And I learned how position attributes are working.

Compliance

In line with Janet regulations and web standards, my web pages focused on accessibility, security, content organization, and usability. To enhance screen reader readability, I have implemented semantic HTML tagging such as <header>, <nav>, and <section>. For the visually impaired audience, I made sure that all images have an alt tag. I also made sure that it is responsive, adding a <meta> tag, and tested the page on several devices as well as having color contrast for reading purposes. The security of user data was taken into consideration, and I made sure that links are done properly. I also validated my code via W3C tools to make sure that my syntax was right and compliant with their standards and thus we could ensure that the pages would meet the required web standards.
